# 概念学习资料生成 Skill

## 用途

根据用户指定的技术概念，生成适合初学者学习、复习和检查的结构化资料。

## 触发方式

当用户说“学习概念”“生成概念资料”或明确要求解释某个技术概念时使用本 Skill。

## 输入

- `concept`：要学习的概念名称。
- `audience`：学习者水平；未提供时默认为入门者。
- `context`：课程、项目或使用场景；未提供时结合概念本身推断。

## 工作流程

1. 明确概念边界：给出一句话定义，并说明它解决什么问题。
2. 解释核心机制：按“组成部分 -> 工作过程 -> 结果”展开，避免只给术语堆砌。
3. 提供一个贴近学习场景的例子，必要时给出简短伪代码或流程。
4. 对比一个容易混淆的相邻概念，指出区别和联系。
5. 总结常见误区、适用边界和实践建议。
6. 生成 3-5 道自测题，并在文末给出参考答案或答题要点。
7. 用“先看结论，再看机制，最后自测”的顺序组织内容，语言准确、简洁。

## 输出格式

```markdown
# <概念名称>

## 一句话定义
## 它解决什么问题
## 核心机制
## 示例
## 与相邻概念的区别
## 常见误区与边界
## 记忆要点
## 自测题
## 参考答案
```

## 质量检查

- 定义不能循环使用概念本身作为唯一解释。
- 示例必须说明输入、过程和预期结果。
- 区分事实、类比和个人建议，不能把类比当成严格定义。
- 对可能随版本变化的内容标注“以当前工具版本为准”。
- 生成完成后检查标题层级、术语一致性、示例完整性和自测答案覆盖度。
